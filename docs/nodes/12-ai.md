# 12. AI

AI nodes. An **AI Agent** answers with a chat model and calls tools; it pulls its model, memory and tools from
sub-nodes connected to its `ai.*` inputs (sub-nodes are not run as steps). **AI Chat** is a standalone prompt node,
and the **Text Splitter**, **Embeddings** and **Vector Store** nodes index documents for retrieval (RAG).
The Chat and MCP Server triggers are in [Triggers](01-triggers.md). See [AI](../14-ai.md) for the architecture,
providers and credential fields.

## Vector Store

Inserts, searches and deletes text chunks in a pgvector table of your PostgreSQL database (`engi.postgres` credential). See [AI 14.10](../14-ai.md#1410-rag-embeddings-text-splitter-and-pgvector) for the table layout and distance handling.
